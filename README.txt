SATRYOTECH — PERSONAL PORTFOLIO
================================

GitHub Pages-ready static website.

ROOT STRUCTURE
- index.html  : halaman utama website
- style.css   : desain, layout, animasi, dan responsive styling
- script.js   : interaksi dan animasi website
- assets/     : foto, dokumentasi, screenshot proyek, sertifikat, dan CV PDF
- README.txt  : panduan ini

DEPLOY KE GITHUB PAGES
1. Extract ZIP ini.
2. Buat repository baru di GitHub.
3. Upload seluruh ISI folder ini ke root repository (jangan upload file ZIP).
4. Pastikan index.html berada langsung di root repository.
5. Buka Settings > Pages.
6. Pada Build and deployment, pilih Deploy from a branch.
7. Pilih branch main dan folder /(root), lalu Save.

CATATAN
- Semua aset website menggunakan path relatif di folder assets/.
- Website ini berupa static site dan dapat di-host di GitHub Pages.
- Form komentar adalah demo front-end dan tidak menyimpan komentar ke server.
- Form kontak membuka aplikasi email melalui mailto; ganti alamat email di script.js dengan alamat email milik Anda.
- Google Fonts membutuhkan koneksi internet.
